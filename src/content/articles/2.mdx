# The Return of Raw Web Design

For the past decade, the web has been drowning in flat illustrations, soft shadows, and meaningless gradients. It's time for a change.

## What is Digital Brutalism?

Brutalism in architecture was about exposing the raw materials—concrete, steel, and glass. In web design, it means exposing the structure. Bare HTML, massive typography, high-contrast borders, and a refusal to hide behind artificial polish.

### Form Follows Function

In a brutalist interface, nothing is hidden. Borders define cells. Typography defines hierarchy. The canvas is exactly what it claims to be.

```css
/* The essence of brutalism */
.container {
  border: 1px solid #111;
  background: transparent;
  color: #111;
  font-weight: 700;
  text-transform: uppercase;
}
```

By removing the decoration, we force ourselves to focus entirely on the content and the engineering.
